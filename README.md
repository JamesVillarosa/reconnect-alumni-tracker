# Re:Connect - Alumni Tracker and Relations Management System 🎓

## Overview
The **Re:Connect** is a web-based platform designed to centralize alumni records, track their achievements, and facilitate communication between the Institute of Computer Science (ICS) and its alumni. The system aims to streamline organizing reunions, fundraising campaigns, and career networking events.

This project is a **Laboratory Project for CMSC 128 - Introduction to Software Engineering** taken on **AY 2024-2025, 2nd Semester**.

## Features ✨
### 1. User Registration and Profile Management 👤
- Alumni can register and update their profiles with personal, educational, and career information.
- Profile verification to ensure authenticity.
- Privacy settings to manage profile visibility.

### 2. Job Posting and Career Opportunities 💼
- Alumni and companies can post job openings for students and fellow alumni.

### 3. Event Management 📅
- Admin can create and manage events such as reunions and webinars, networking events.
- RSVP functionality for alumni.
- Event reminders and notifications.

### 4. Alumni Search and Networking 🔍
- Filter alumni by graduation year, field of work, location, or skills.

### 5. Donations and Sponsorships 🎁
- Facilitate alumni contributions for scholarships, events, and fundraising campaigns.
- Transparent tracking of donation history.

### 6. Communications Module 📢
- Send articles, newsletters, and invitations to alumni.
- Automated email and notification system.
- Discussion boards or forums for engagement.

### 7. Reports and Analytics 📊
- Generate statistics, such as the number of active alumni, their current industries, and donation trends.
- Admin dashboard for insights and system monitoring.
- Exportable reports for stakeholders.

## Contribution Guidelines 🤝

### Issue Naming Convention 📝
Use the following format:
```
[Type] Short Description
```
**Types:**
- `Feature:` For new functionalities.
- `Bug:` For fixes.
- `Refactor:` For code improvements.
- `Docs:` For documentation updates.

**Example:**
Take note of capitalizations.
```
[Feature] Add alumni profile editing functionality
[Bug] Fix broken RSVP button on event page
```

### Commit Naming Convention 📌
Follow this structure:
```
<type>: <short description>
```
**Types:**
- `feat:` New feature ✨
- `fix:` Bug fix 🐛
- `refactor:` Code improvements 🔧
- `docs:` Documentation updates 📖
- `chore:` Maintenance tasks 🔄

**Example:**
Write everything in lowercase.
```
feat: add search filter for alumni
fix: resolve UI bug on profile page
```

### Pull Request Naming Convention 🔄
Use the following format:
```
[Type] Short Description (#issue-number)
```
**Example:**
Take note of capitalizations.
```
[Feature] Implement job posting system (#15)
[Bug] Fix login authentication error (#22)
```
